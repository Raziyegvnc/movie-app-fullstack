# 🎬 Movie App (Full Stack)

This is a full-stack movie search application built with **React**, **Node.js**, and **Express**.  
The application allows users to search movies and view details such as title, year, and poster using the OMDb API.

---

## 🚀 Features

- Movie search functionality
- Display movie posters, titles, and release years
- Real-time API integration (OMDb)
- Backend API layer (Express)
- Secure API key usage with environment variables
- Frontend-backend separation (Full Stack architecture)

---

## 🧠 Tech Stack

### Frontend
- React
- JavaScript (ES6+)
- CSS

### Backend
- Node.js
- Express.js
- Axios
- dotenv
- CORS
